## 🛡️ v10 Engine — Technical Architecture

The v10 engine is not just a version number — it is a complete architectural overhaul that makes DigitopiaVP2 production-ready for serious trading environments.

### Multi-Instance Safety

Each indicator instance operates in a completely **isolated object namespace**. You can load 5 DigitopiaVP2 instances on the same chart — each with its own Start/End lines, its own profile, its own Confidence Score — with **zero object naming conflicts** and zero visual interference.

This is a solved engineering problem that most competitors ignore entirely.

### Memory Management

The `MAX_TICK_LOAD` safety parameter caps the number of ticks processed per calculation cycle. This prevents the indicator from consuming unbounded memory on instruments with ultra-high tick rates (XAUUSD, EURUSD, crypto pairs), eliminating the crashes and terminal freezes common with naive volume profile implementations.

### Anti-Overlap Label Engine

The POC, VAH and VAL labels are rendered by a dedicated positioning algorithm that detects and resolves vertical overlaps before drawing. On tight price ranges or compressed charts, the labels reposition automatically — they remain legible, non-overlapping and correctly associated with their price levels at all times.

### Auto Cleanup

When the user changes timeframes, the indicator fires a full object cleanup routine before reinitializing. No ghost objects, no orphaned lines or bars left on the chart from previous timeframes. Clean state, every time.

### Performance

| Metric | Value |
|:---|:---|
| Calculation trigger | OnCalculate + OnChartEvent |
| Object management | Full creation/deletion lifecycle |
| Tick safety limit | Configurable via `MAX_TICK_LOAD` |
| Memory footprint | Optimized for multi-instance use |
| Chart event handling | Drag events for Start/End line interactivity |

## 💡 Use Cases & Strategies

### Strategy 1: Sniper Entry at VAL/VAH Rejection

```
Condition: Price approaches VAH from below
Confluence: Confidence Score → SELL > 58%
           → Delta turns negative at VAH
           → LVN above VAH (no support above)
Action: Short at VAH retest
Target: vPOC, then VAL
Stop: Above VAH + ATR buffer
```

### Strategy 2: POC Magnet Trade

```
Condition: Price is far from vPOC (> 0.5% deviation)
Confluence: Confidence Score neutral (~50%)
           → Low delta imbalance
           → No strong HVN between price and POC
Action: Fade the move back toward vPOC
Target: vPOC
Stop: Beyond the HVN/LVN zone
```

### Strategy 3: HVN Support/Resistance

```
Condition: Price pulls back to a major HVN zone
Confluence: Confidence Score → BUY > 55%
           → Delta turns positive at HVN
           → BOS confirmed on lower timeframe
Action: Long at HVN with positive delta confirmation
Target: VAH or next HVN above
Stop: Below HVN (LVN acts as accelerator if broken)
```

### Strategy 4: LVN Breakout Acceleration

```
Condition: Price breaks through an LVN zone with momentum
Confluence: Confidence Score → dominant direction > 60%
           → Strong delta in breakout direction
Action: Enter on LVN break retest, expect fast move
Target: Next HVN
Stop: Back inside LVN (false break)
```
